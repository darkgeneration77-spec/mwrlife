## GitHub Pages
将 `index.html`、`.nojekyll` 和 `README.md` 放到仓库根目录，在 Settings → Pages 选择 main / root。

**发布前检查**：当前仍保留 `noindex,nofollow,noarchive` 以免测试站被收录。准备公开时审核营销合规、品牌使用及外部图片授权，并在确认后修改 robots 设置。核对官方链接和各设备浏览器实际显示。
